# FTC part designs

> **Work in progress.** These designs are new and still changing, and some parts are not yet built and
> tested on a robot. Please try them and [tell us what works and what does not](https://github.com/crossbotics/ftc-part-designs/issues)
> (a GitHub issue). Every report helps.

Robot part designs for FIRST Tech Challenge (FTC) teams, made in [build123d](https://github.com/gumyr/build123d)
(Python CAD). Each part has a 3D page on [crossbotics.com](https://crossbotics.com) with the design decisions,
the checks behind them, and a parts list with real, off-the-shelf part numbers.

One folder per season:

| Season | Parts |
| --- | --- |
| [2026-2027-BioBuzz](2026-2027-BioBuzz/) | Swivel turret shooter (v8.1GB) |

Ready-made files (STEP, STL, DXF, printed prototype kit) are on the [releases page](https://github.com/crossbotics/ftc-part-designs/releases).

Companion project: [FTC-Helper-Lib](https://github.com/crossbotics/ftc-helper-lib), a Java library and simulator
for FTC robot code.
